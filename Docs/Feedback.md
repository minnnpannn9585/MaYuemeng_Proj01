# 森林交互特效与音效

本次保留已有场景、角色和交互规则，在现有 `InteractionFeedback.Play` 接口上重做表现层。

## 在 Unity 中预览

1. 用 Unity 2022.3.62f3 打开项目，运行任意关卡。
2. 打开 **Tools → Forest → Feedback Preview**。
3. 点击各事件名称；可以分别开关声音、粒子，调整强度。
4. 运行时选中 Hierarchy 中的 **InteractionFeedback**，调整 **Master Volume** 与 **Effect Scale**。运行中修改不会保存到下一次运行；要更改默认值，修改脚本中的字段初始值。

音效位于 `Assets/Resources/Feedback/Audio`，可以在 Inspector 中单独试听、替换同名 WAV。`LaserSpark` 刻意无声，持续激光接触只在首次命中发声。

## 表现设计

- 跳跃、落地、花盆落地：柔和尘雾、少量叶屑、扁平地面涟漪；强落地具有更明显的反馈。
- 拾取、钻石：奶金色四角星、薄光环及短暂柔光，避免整团圆点遮挡角色。
- 弹跳、植物生长：薄荷绿叶片、淡粉花瓣、上扬的细小星芒。
- 时间切换、传送门：两层青紫涟漪、光屑与柔和的空气扫频。
- 激光：细亮芯、半透明软边、短促接触火花；连续火花不反复响。
- 音效：33 个原创程序合成的 48 kHz、16-bit 立体声 WAV。以滤波拟音、陶器共振、气流、钟音和短反射构成；不是录制的真实环境声音。常用动作有 2–3 个变体，并避免连续重复同一变体。

## 检查与修复

- 修复第三关整屏消失：发光区域在 `AddComponent` 的 `OnEnable` 中，曾使用尚未配置的 Everything 图层掩码把角色、地面、背景都变成隐藏平台。自动注册现在只作用于 `HiddenPlatformReveal` 专用图层，默认掩码也收窄到该图层。
- 钻石旧预制体曾绕过统一粒子。默认使用新版，保留 `Use Legacy Collect Effect` 作为显式回退。
- 钻石增加收集锁，避免同一帧多个碰撞回调重复反馈；旧预制体回退路径也会自动销毁。
- 跳跃反馈移动到实际施加跳跃速度时；传送、复活、植物弹跳重置落地反馈状态，防止误响。
- 视觉随机数独立于游戏随机数，避免特效影响蝙蝠逃跑方向等逻辑。
- 粒子池最多 56 层、声音最多 12 个声部；单场景切换清理旧粒子，保留传送音尾。
- 材质和激光生成材质在销毁时释放；资源中的 Shader 明确打入构建，不依赖运行时 `Shader.Find` 猜测。
- 激光、蝙蝠和显形声音随与摄像机的距离衰减，避免另一条时间线的环境事件在耳边响起。

## 再生成与验证

音效生成：`python Tools/generate_feedback_audio.py`，需要 NumPy。固定种子使输出可重现；WAV 自带约 4.4 dB 峰值余量，含首尾淡入淡出。Unity 中的混音还会进一步降低增益。

批处理检查：Unity 命令行添加 `-batchmode -projectPath <项目目录> -executeMethod FeedbackValidation.RunBatch -logFile <日志路径>`。不要传 `-quit`，验证完成后会自动退出。

验证脚本在 Play 模式逐一载入三个关卡，检查资源、Shader、18 个事件、对象池上限、粒子到期、随机数隔离、钻石去重、声音播放/冷却/距离衰减，以及发光区域不会误隐藏角色，并在 `Logs/FeedbackQA` 输出实际引擎截图和结果。此过程不保存场景。预览工具与验证脚本位于 Editor 目录，不进入游戏构建。

`Logs/FeedbackQA/sound-preview.wav` 为素材串听，顺序是跳跃、落地、花盆碰撞、弹跳、收集、时间切换；各段之间有短暂停顿。

这套自动检查不替代实际通关和耳机试听。最终音量、角色遮挡和连续游玩的疲劳度，仍建议在目标设备上确认。
